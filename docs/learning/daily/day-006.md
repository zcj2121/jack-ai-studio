## 必备理论

### 1. Module（模块）

**专业解释：**

Python Module 通常是一个 `.py` 文件，用于组织可导入、可复用的变量、函数和类型。

**大白话：**

它类似 TypeScript 的 `.ts` 文件。文件既能被直接运行，也能被其他模块导入复用。

**举例：**

`apps/api/app/main.py` 是今天的入口模块。

**在 Jack AI Studio 中的作用：**

后续 API 会把 routes、services、providers、rag 和 agents 拆成不同模块。今天只建立最小入口，不提前创建未来分层。

### 2. list 与 dict（列表与字典）

**专业解释：**

`list` 是有顺序、可修改的元素集合；`dict` 使用 key-value（键值对）保存数据。

**大白话：**

它们分别接近 JavaScript 的 Array 和普通 Object，但 Python 使用不同语法。

**举例：**

```python
service_info = {"name": "Jack AI Studio API"}
capabilities = ["Provider integration", "Conversation management"]
```

**在 Jack AI Studio 中的作用：**

今天用它们表达服务元信息和计划能力；未来请求、消息和检索结果也会包含集合与键值数据，但会使用更严格的 Schema。

### 3. Function（函数）

**专业解释：**

Function 把一段有明确输入、处理过程和输出的逻辑封装为可复用单元，Python 使用 `def` 定义函数。

**大白话：**

它和 TypeScript 函数的职责相同，只是语法、缩进和类型写法不同。

**举例：**

`format_service_status(...) -> str` 接收服务信息，返回终端状态文本。

**在 Jack AI Studio 中的作用：**

后续 API 路由会调用服务函数处理模型请求。今天只练习纯文本格式化，不处理网络 IO。

### 4. Type Hints（类型提示）

**专业解释：**

Type Hints 描述变量、函数参数和返回值的预期类型，供编辑器和静态检查工具分析。Python 默认不会像 TypeScript 编译阶段那样全面强制类型。

**大白话：**

它像 TypeScript 类型标注，是协作和检查依据，但不能把它误认为运行时数据校验。

**举例：**

```python
def main() -> None:
    ...
```

**在 Jack AI Studio 中的作用：**

后续会用它明确 API Schema、服务层和 Provider 的数据契约。真正的请求校验会在对应学习日引入 Pydantic。

### 5. Entry Point（程序入口）

**专业解释：**

Entry Point 是程序开始执行的约定位置。Python 文件被直接执行时，`__name__` 为 `"__main__"`；被导入时则是模块名。

**大白话：**

这相当于给文件加一个判断：只有直接运行时才启动，其他代码 import 它时不会自动执行。

**举例：**

```python
if __name__ == "__main__":
    main()
```

**在 Jack AI Studio 中的作用：**

今天用于启动终端状态程序。它不是 FastAPI Server，也不会监听端口。

## Python 学习

### TypeScript 与 Python 对照

| TypeScript | Python |
| --- | --- |
| `const names: string[] = []` | `names: list[str] = []` |
| `const info = { name: "API" }` | `info = {"name": "API"}` |
| `function format(): string` | `def format() -> str:` |
| `{}` 表示代码块 | 缩进表示代码块 |
| 编译器执行静态类型检查 | Type Hints 需要静态检查工具配合 |

## 关键代码说明

- `SERVICE_INFO` 使用 `dict[str, str]` 保存键值数据。
- `PLANNED_CAPABILITIES` 使用 `list[str]` 保存有序文本。
- `format_service_status` 只负责生成文本，没有打印等外部副作用。
- `main` 负责程序启动行为，保持职责清晰。
- `__main__` 判断避免模块被导入时自动执行 `main()`。
- `sys.version_info` 读取真实 Python 主次版本，避免把运行环境硬编码到输出。

## 今日英文术语

1. **Module**：组织 Python 代码的模块。
2. **Package**：包含模块的 Python 包。
3. **Function**：封装可复用逻辑的函数。
4. **Parameter**：函数定义中的参数。
5. **Return Value**：函数返回值。
6. **list**：有序、可修改的元素集合。
7. **dict**：使用键值对保存数据的字典。
8. **Type Hints**：描述预期类型的类型提示。
9. **Entry Point**：程序开始执行的入口。
10. **Standard Library**：Python 自带、无需额外安装的标准库。
