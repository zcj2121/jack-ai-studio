## 必备理论

### 1. Event（事件）

**专业解释：**

Event 是浏览器对点击、输入、提交等用户操作的结构化描述。React 通过事件处理函数读取事件，并根据业务规则更新 State。

**大白话：**

它像 Vue 中的 `@click` 和 `@input`：用户做了一个动作，组件收到通知后决定如何处理，而不是浏览器直接修改业务数据。

**举例：**

`onChange={handlePromptChange}` 会在输入变化时执行，事件对象中的 `event.target.value` 是输入框当前内容。

**在 Jack AI Studio 中的作用：**

今天处理 Prompt 输入、清空和提交。未来发送消息、选择 Provider 和上传文档也会从事件开始。

### 2. Controlled Component（受控组件）

**专业解释：**

受控组件是指表单元素的当前值由 React State 控制。界面通过 `value` 读取 State，再通过 `onChange` 请求更新 State。

**大白话：**

可以把它看成 Vue `v-model` 的展开形式：

```tsx
<textarea value={prompt} onChange={handlePromptChange} />
```

State 是唯一账本，输入框只负责展示和报告变化。

**举例：**

调用 `setPrompt("")` 后，State 变为空字符串，React 重新渲染，输入框也随之清空。

**在 Jack AI Studio 中的作用：**

Prompt 内容、实时字数和按钮禁用状态都由同一个 `prompt` State 推导，便于后续增加校验。

### 3. Unidirectional Data Flow（单向数据流）

**专业解释：**

单向数据流表示数据从 State 流向 UI，用户事件再触发 State 更新，更新后的 State 重新驱动 UI。每一步都有明确方向。

**大白话：**

像企业后台里的标准流程：数据先下发到表单，用户操作产生事件，处理函数更新数据，页面再按新数据展示。不会让 DOM 和业务变量互相偷偷修改。

**举例：**

```text
prompt State
    ↓ value
textarea
    ↓ onChange Event
setPrompt
    ↓
新的 prompt State
```

**在 Jack AI Studio 中的作用：**

明确的数据流能让 Chat 输入、发送状态和校验逻辑更容易调试。今天只练习局部组件的数据流。

### 4. Derived State（派生状态）

**专业解释：**

派生状态是能够从现有 State 直接计算得到的数据，通常不应再保存一份独立 State，以避免两份数据不同步。

**大白话：**

如果已经知道商品单价和数量，总价就现场计算，不需要再维护一本“总价账”。

**举例：**

`canSubmit` 直接由 `prompt.trim().length > 0` 计算，不再使用一个额外的 `isDisabled` State。

**在 Jack AI Studio 中的作用：**

今天用于提交按钮的禁用状态；未来 Token 估算、过滤结果等也可能是派生数据。

### 交互规则

- 输入内容时，`onChange` 更新 `prompt` State。
- 字数由 `prompt.length` 实时计算，最多 280 字。
- 仅空白内容不能提交。
- 点击清空会将 `prompt` 设为空字符串。
- 本地提交会阻止浏览器默认刷新，并展示最后一次提交内容。
- 所有数据只存在于组件内，刷新页面后消失。

## 关键代码说明

- `ChangeEvent<HTMLTextAreaElement>` 精确描述文本域变更事件。
- `FormEvent<HTMLFormElement>` 精确描述表单提交事件。
- `event.preventDefault()` 阻止原生表单提交导致页面刷新。
- `normalizedPrompt` 和 `canSubmit` 都从现有 State 派生，不重复保存。
- 提交按钮保留原生 `disabled` 属性，使视觉状态和交互语义一致。
- `aria-live` 用于播报字数和提交预览变化。

## 今日英文术语

1. **Event**：事件，用户操作的结构化描述。
2. **Event Handler**：事件处理函数。
3. **Controlled Component**：值由 React State 控制的表单组件。
4. **Unidirectional Data Flow**：单向数据流。
5. **Form**：表单。
6. **Submit**：提交表单。
7. **Change Event**：输入值变化事件。
8. **Derived State**：由现有状态计算出的派生数据。
9. **Validation**：校验输入是否符合规则。
