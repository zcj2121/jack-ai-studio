## 必备理论

### 1. HTTP Request 与 Response（请求与响应）

**专业解释：**

HTTP 是客户端和服务器通信的应用层协议。客户端发送 Request，服务器处理后返回包含 Status Code、Headers 和 Body 的 Response。

**大白话：**

前端像提交一张办事单：地址和 Method 说明要办什么，服务器处理后用状态码和数据给出结果。

**举例：**

```text
GET /health HTTP/1.1
        ↓
HTTP/1.1 200 OK
Content-Type: application/json
{...服务状态...}
```

**在 Jack AI Studio 中的作用：**

Web 前端、未来第三方客户端和 Python 后端会通过 HTTP 通信。今天只验证最小读取链路。

### 2. FastAPI

**专业解释：**

FastAPI 是基于 Python Type Hints、Starlette 和 Pydantic 构建的 ASGI Web Framework，用于定义路由、处理请求并生成响应。

**大白话：**

它可以类比 Koa 加 Router，再加上与 Pydantic 的自动数据校验和文档集成。

**举例：**

```python
app = FastAPI()
```

创建一个 API Application（应用实例）。

**在 Jack AI Studio 中的作用：**

后续 Chat、Provider、RAG、Agent 和 MCP 等后端能力都会通过 FastAPI 暴露 API。今天只创建最小应用实例。

### 3. Endpoint（接口端点）

**专业解释：**

Endpoint 由 HTTP Method 和 URL Path 共同确定，对应一个处理请求的 Path Operation Function。

**大白话：**

Method 是“要做什么”，Path 是“找谁办理”。只有两者组合起来，才能确定具体接口。

**举例：**

`GET /health` 与 `POST /health` 是两个不同 Endpoint。

**在 Jack AI Studio 中的作用：**

今天建立健康检查 Endpoint；未来会有 Chat、Conversation 和 Provider 等接口。

### 4. GET

**专业解释：**

GET 是用于读取资源的 HTTP Method，按语义通常不应修改服务器业务状态。

**大白话：**

它类似后台系统里的查询按钮：只读取，不新增、修改或删除业务数据。

**举例：**

浏览器访问 `/health` 时发送 GET Request，服务器返回当前状态。

**在 Jack AI Studio 中的作用：**

后续可用于读取会话列表、知识库列表和模型配置。今天只读取服务健康状态。

### 5. ASGI 与 Uvicorn

**专业解释：**

ASGI 是 Python 异步 Web Server 和 Web Application 之间的标准接口；Uvicorn 是实现该接口、负责监听端口并把请求交给 FastAPI 的 Server。

**大白话：**

FastAPI 定义“收到请求后怎么办”，Uvicorn 负责“真正开门营业”。ASGI 是它们之间统一的插座标准。

**举例：**

```bash
uvicorn app.main:app --app-dir apps/api
```

`app.main` 是模块，冒号后的 `app` 是模块中的 FastAPI 实例。

**在 Jack AI Studio 中的作用：**

Uvicorn 让 FastAPI 应用真正监听 HTTP 请求；ASGI 为未来并发请求和流式响应提供运行基础。

### 6. Decorator（装饰器）

**专业解释：**

Decorator 使用 `@` 语法为函数注册或附加行为。FastAPI 的 Path Operation Decorator 会把函数绑定到 Method 和 Path。

**大白话：**

它像给函数贴标签：“这个函数负责处理 GET /health”。

**举例：**

```python
@app.get("/health")
async def get_health():
    ...
```

**在 Jack AI Studio 中的作用：**

后续每个 API 路由都会用相同方式声明自己的 Method、Path 和响应模型。

### 7. async def（异步函数）

**专业解释：**

`async def` 定义 Coroutine Function（协程函数），在遇到支持 `await` 的 I/O 时可以暂停当前任务，让事件循环处理其他工作。

**大白话：**

它类似 Koa 中的 `async (ctx) => {}`。等待模型 API、数据库或网络响应时，服务不必让整个进程原地空等。

**举例：**

今天的 `/health` 没有外部 I/O，因此函数中还没有 `await`；它只是先建立 FastAPI 异步路由写法。

**在 Jack AI Studio 中的作用：**

后续调用模型 Provider、数据库和工具时会产生大量网络 I/O，异步能力会直接影响并发处理。

## Python 学习

### Koa 与 FastAPI 对照

| Koa / Node.js | FastAPI / Python |
| --- | --- |
| `const app = new Koa()` | `app = FastAPI()` |
| `router.get("/health", handler)` | `@app.get("/health")` |
| `async (ctx) => {}` | `async def get_health()` |
| `ctx.body = data` | `return data` |
| Node.js HTTP Server | Uvicorn ASGI Server |
| TypeScript + Zod | Type Hints + Pydantic |

### 当前 HTTP 数据流

```text
浏览器或 curl
      ↓ GET /health
Uvicorn（监听 127.0.0.1:8000）
      ↓ ASGI
FastAPI 路由匹配
      ↓
get_health()
      ↓
ServiceStatus
      ↓ 自动序列化
HTTP 200 + JSON Response
```

## 项目实战

### 核心代码

```python
app = FastAPI(
    title="Jack AI Studio API",
    version="0.1.0",
)


@app.get("/health", response_model=ServiceStatus)
async def get_health() -> ServiceStatus:
    return build_service_status(
        SERVICE_INFO,
        PLANNED_CAPABILITIES,
    )
```

`response_model=ServiceStatus` 声明响应契约，返回值还会经过 Pydantic 模型序列化。

### 启动

```bash
uv run uvicorn app.main:app \
  --app-dir apps/api \
  --host 127.0.0.1 \
  --port 8000
```

今天不使用 `--reload`，避免把文件监听环境问题混入第一个 HTTP Endpoint 的学习。

### 访问

```text
http://127.0.0.1:8000/health
http://127.0.0.1:8000/docs
```

## 关键代码说明

- `FastAPI(...)` 创建应用实例，但它本身不监听网络端口。
- Uvicorn 负责加载 `app.main:app` 并监听 `127.0.0.1:8000`。
- `@app.get("/health")` 将 Method、Path 和处理函数绑定。
- `get_health()` 返回 `ServiceStatus`，FastAPI 自动生成 JSON Response。
- `response_model=ServiceStatus` 明确响应 Schema。
- `if __name__ == "__main__"` 仍保护终端示例；Uvicorn 导入模块时不会执行 `main()`。

## 今日英文术语

1. **HTTP**：客户端与服务器交换请求和响应的协议。
2. **Request**：客户端发送给服务器的请求。
3. **Response**：服务器返回给客户端的响应。
4. **Status Code**：表示处理结果的 HTTP 状态码。
5. **Endpoint**：由 Method 和 Path 确定的接口端点。
6. **GET**：读取资源的 HTTP Method。
7. **JSON**：前后端常用的结构化数据格式。
8. **ASGI**：异步 Server 与 Application 的标准接口。
9. **Uvicorn**：运行 ASGI 应用的 Server。
10. **Decorator**：使用 `@` 为函数注册或附加行为的语法。
