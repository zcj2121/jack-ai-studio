# Day 5：使用 App Router 建立 Chat 页面骨架

## 今日目标

1. 理解 Route、File-system Routing、Route Segment 和 Client-side Navigation。
2. 掌握 Next.js `page.tsx` 与 URL 的映射规则。
3. 使用 `<Link>` 在首页和 Chat 页面之间导航。
4. 建立 `/chat` 静态页面骨架，并继续判断 Server / Client Component 边界。

今天只建立页面与导航关系，不实现真实消息、模型调用、会话管理、流式响应或 API。

## 必备理论

### 1. Route（路由）

**专业解释：**

Route 是 URL 与应用页面内容之间的映射规则。用户访问特定路径时，路由系统决定渲染哪个页面。

**大白话：**

它和 Vue Router 的路由记录解决同一个问题：根据地址找到对应页面。

**举例：**

访问 `/chat` 时，Next.js 渲染 `app/chat/page.tsx`。

**在 Jack AI Studio 中的作用：**

首页、Chat、Knowledge 和 Agent Center 最终都会拥有各自的 Route。今天只新增 `/chat`。

### 2. File-system Routing（文件系统路由）

**专业解释：**

File-system Routing 使用目录和特定文件约定生成路由，不需要集中维护一份路由配置数组。

**大白话：**

Vue Router 常写 `{ path: "/chat", component: Chat }`；Next.js 则通过 `app/chat/page.tsx` 的位置表达同一件事。

**举例：**

```text
src/app/page.tsx       → /
src/app/chat/page.tsx  → /chat
```

**在 Jack AI Studio 中的作用：**

今天用最小目录结构建立 Chat 页面，后续功能会按产品模块继续组织，但当前不创建未来页面。

### 3. Route Segment（路由片段）

**专业解释：**

Route Segment 是 URL 路径中由 `/` 分隔的一部分，在 App Router 中通常对应一个文件夹。

**大白话：**

把 URL 看成目录地址，`/chat` 中的 `chat` 就是一段路径。

**举例：**

未来 `/chat/123` 可以包含 `chat` 和 `123` 两个 segment，但今天不学习动态路由。

**在 Jack AI Studio 中的作用：**

`chat` segment 用来隔离 Chat 模块的页面边界。

### 4. Link 与 Client-side Navigation（客户端导航）

**专业解释：**

Next.js `<Link>` 为应用内部路由提供可访问链接，并支持 Prefetch（预取）与 Client-side Transition（客户端切换），避免传统导航每次完整刷新页面。

**大白话：**

它类似 Vue Router 的 `<RouterLink>`：仍然是链接语义，但框架会让页面切换更快、更平滑。

**举例：**

```tsx
<Link href="/chat">进入 Chat</Link>
```

**在 Jack AI Studio 中的作用：**

今天用于首页进入 Chat，以及 Chat 返回首页。链接本身不要求页面变成 Client Component。

## Python 学习

今天不新增 Python 代码。需要先理解 Web 页面路由与后端 API 路由不是一回事：

- `/chat` 页面路由返回用户界面。
- 未来 Python API 路由会返回数据。

二者都使用 URL，但职责不同，不能因为名字相同就混在一起。

```text
首页 /
  │
  └── <Link href="/chat">
          ↓
      Chat /chat
          │
          └── <Link href="/">返回首页
```

## 关键代码说明

- 只有包含 `page.tsx` 的 segment 才会暴露为页面路由。
- `chat/page.tsx` 不使用事件、State 或浏览器 API，因此保持 Server Component。
- `<Link>` 可以在 Server Component 中使用，不需要添加 `"use client"`。
- 静态列表使用稳定文本作为 `key`。
- 禁用输入区使用静态说明，不使用一个无法交互却看似可用的表单控件。

## 今日英文术语

1. **Route**：URL 与页面的映射。
2. **Routing**：根据 URL 选择页面的过程。
3. **File-system Routing**：通过文件目录约定生成路由。
4. **Route Segment**：URL 中的一段路径。
5. **Page**：App Router 中通过 `page.tsx` 暴露的页面。
6. **Link**：Next.js 的内部导航组件。
7. **Navigation**：页面之间的导航过程。
8. **Client-side Transition**：不完整刷新文档的客户端页面切换。
9. **Prefetch**：用户点击前预先获取可能需要的路由资源。
